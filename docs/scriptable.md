# Scriptable 위젯 설치

## 1. 스크립트 넣기

1. App Store에서 **Scriptable** 설치 (무료).
2. 이 레포의 `scriptable/FocusWidget.js` 내용을 전부 복사.
   GitHub 앱이나 웹에서 파일 열기 → Raw → 전체 선택 → 복사.
3. Scriptable → 오른쪽 위 **+** → 붙여 넣기.
4. 맨 위의 두 줄을 내 값으로 바꾸기:
   ```js
   const BASE_URL = 'https://내-앱-주소.vercel.app';
   const API_TOKEN = 'Vercel에 넣은 API_TOKEN 값';
   ```
5. 위쪽 제목을 눌러 이름을 **FocusCurve**로 바꾸고 완료.
6. 스크립트를 한 번 눌러 실행 → 큰 위젯 미리보기가 뜨면 성공.
   `불러오기 실패`가 뜨면 주소 끝에 `/`가 두 번 붙지 않았는지, 토큰이 맞는지 확인.

## 2. 홈 화면 위젯

1. 홈 화면 빈 곳 길게 누르기 → 왼쪽 위 **편집** → **위젯 추가** → **Scriptable**.
2. 크기 고르기: 작은 것 / 중간 / 큰 것 → 위젯 추가.
3. 추가된 위젯을 길게 누르기 → **위젯 편집**:
   - Script: **FocusCurve**
   - When Interacting: **Run Script** 말고 **Open URL**을 고르고 비워 두면
     스크립트 안에 넣어 둔 웹앱 주소가 열린다. (그냥 기본값으로 둬도 됨)

| 크기 | 보이는 것 |
|---|---|
| 작은 것 | 상태(상승/피크/감소/효과 끝), 효과 끝까지 남은 시간, 작은 곡선 |
| 중간 | 위 내용 + 카페인 농도·수면 가능 시각 + 곡선 (지난 8시간~앞으로 12시간) |
| 큰 것 | 메틸페니데이트 곡선 + 카페인 곡선 + 오늘 카페인/권고량 |

## 3. 잠금화면 위젯

잠금화면 길게 누르기 → **사용자화** → 잠금 화면 → 시계 아래 위젯 칸 → Scriptable.

- 직사각형: 상태·%, 효과 끝까지 타이머, 카페인 수면 가능 시각
- 원형: 지금 % 와 상태
- 시계 위 한 줄: 상태 · %

추가한 뒤 위젯을 한 번 더 눌러 Script를 **FocusCurve**로 지정.

## 참고

- 새로고침 간격은 iOS가 정한다. 스크립트는 20분 뒤를 요청하지만 실제로는 15분~1시간쯤.
  곡선은 위젯 안에서 기록으로 직접 계산하니까 새로고침이 늦어도 모양은 맞다.
  **효과 끝까지 타이머는 새로고침 없이도 1초 단위로 줄어든다.**
- 네트워크가 안 되면 마지막으로 받은 기록으로 그린다 (큰 위젯 아래 `오프라인` 표시).
- 웹앱을 업데이트해서 `scriptable/FocusWidget.js`가 바뀌면 1번을 다시 하면 된다.
  (BASE_URL, API_TOKEN 두 줄만 다시 바꾸기)
