# 단축어 설정

모든 단축어에서 쓰는 값:
- 주소: `https://내-앱-주소.vercel.app`
- 토큰: Vercel의 `API_TOKEN` 값

액션 이름은 한국어 iOS 기준. 액션 검색창에 이름을 치면 나온다.

---

## 1. 콘서타 복용 버튼 (+ PVT 알림 자동 예약)

단축어 앱 → **+** → 이름 `콘서타 복용`.

1. **URL** 액션
   `https://내-앱-주소.vercel.app/api/dose`
2. **URL 내용 가져오기** 액션
   - 방법: **POST**
   - 헤더 → 새로운 헤더 추가: 키 `Authorization`, 값 `Bearer 토큰`
     (Bearer 뒤에 한 칸 띄우고 토큰)
   - 요청 본문: **JSON**
     - 새로운 필드 → 텍스트: 키 `drug`, 값 `concerta`
     - 새로운 필드 → 숫자: 키 `mg`, 값 `18`
3. **사전에서 값 가져오기** 액션: 키 `message`
4. **알림 보기** 액션: 내용에 3번 결과(사전 값)

여기까지가 기록. 아래는 복용 후 2시간마다 PVT 알림을 거는 부분 (선택):

5. **현재 날짜** 액션
6. **날짜 조정** 액션: 현재 날짜에 **2 시간 더하기**
7. **새로운 미리 알림 추가** 액션
   - 내용: `PVT 하기`
   - 목록: 새 목록 `PVT` 를 미리 만들어 두고 선택
   - 알림: **켬**, 날짜: 6번 결과(조정된 날짜)
   - URL: `https://내-앱-주소.vercel.app/pvt`
8. 6~7번을 **4, 6, 8, 10시간**으로 바꿔서 4번 더 복사.

알림이 오면 미리 알림을 눌러 링크를 열고 1분 테스트. 느낌과 상관없이 알림이 올 때마다 하는 게 중요하다.
약 안 먹은 날에도 비슷한 시각에 몇 번 해 두면 평소 기준이 정확해진다.

## 2. 카페인 버튼

1번을 복제(길게 누르기 → 복제)하고:
- 이름: `몬스터 마심`
- `drug` 값 `caffeine`, `mg` 값 `100`
- 5~8번 (PVT 알림) 삭제

아메리카노 등은 mg만 바꿔 하나씩 더 만든다. 잘 모르는 음료면 **숫자 입력 요청** 액션을
2번 앞에 넣고 `mg` 필드 값으로 그 결과를 쓰면 매번 물어본다.

## 3. 홈 화면에 버튼 놓기

- 단축어 길게 누르기 → 공유 → **홈 화면에 추가** (아이콘 하나씩), 또는
- 홈 화면 편집 → 위젯 추가 → **단축어** 위젯 → 위 단축어들이 버튼으로 나온다.

## 4. 잠든 시각 기록 (카페인 수면선 보정용)

### 방법 A: 아침에 물어보기 (애플워치 없으면 이쪽)

단축어 이름 `어젯밤 잠든 시각`:

1. **날짜 입력 요청** 액션: 질문 `어젯밤 몇 시에 잠들었어?`, 입력 유형 **날짜 및 시간**
2. **날짜 포맷** 액션: 1번 결과, 날짜 포맷 **ISO 8601**, 시간 포함 켬
3. **URL** → `https://내-앱-주소.vercel.app/api/sleep`
4. **URL 내용 가져오기**: POST, 헤더 Authorization 같게, JSON 필드 텍스트 `sleepStart` = 2번 결과
5. **알림 보기**: `저장했어요`

자동화 탭 → **+** → 개인용 자동화 → **특정 시간** 오전 8시, 매일 → **즉시 실행** →
단축어 실행: `어젯밤 잠든 시각`. 알림을 누르면 질문이 뜬다.

### 방법 B: 건강 앱에서 자동으로 (수면 데이터가 기록될 때)

1. **건강 샘플 찾기** 액션
   - 유형: **수면 분석**
   - 필터: 시작 날짜 **지난 1일**, 값 **잠자리에 있음 아님**
   - 정렬: 시작 날짜, **오래된 것부터**, 제한 켬 **1**
2. **세부사항 가져오기** → **시작 날짜**
3. 이후는 방법 A의 2~5번과 같음

수면 데이터가 없으면 아무것도 안 올라가니까 웹앱 기록 화면에서 직접 넣어도 된다.

## 5. 효과 시작/끝 버튼 (선택)

1번을 복제 → 주소 `/api/effect`, JSON 필드 텍스트 `type` = `start` (또는 `end`), mg 필드 삭제, 5~8번 삭제.
웹앱 대시보드의 효과 시작/끝 버튼과 같다.

## 문제 생길 때

- 알림에 `unauthorized` → 헤더 값이 `Bearer 토큰` 형식인지 확인 (Bearer 대소문자, 띄어쓰기).
- `drug는 concerta 또는 caffeine` → 필드 키를 `drug`로 썼는지, 값에 공백이 없는지.
- 시각을 지정하고 싶으면 JSON에 텍스트 필드 `time` = `2026-11-28 08:10` 형식으로 넣으면 된다 (한국 시간).
